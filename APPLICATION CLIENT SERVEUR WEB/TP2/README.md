TP2 – Applications 2-tiers et 3-tiers

Présentation

Ce travail pratique porte sur l’architecture des applications 2-tiers et 3-tiers, ainsi que sur leur mise en œuvre dans un environnement virtualisé.

Objectifs

* Comprendre le fonctionnement des architectures 2-tiers et 3-tiers.
* Mettre en place une base de données MariaDB.
* Configurer la communication entre les machines virtuelles.
* Développer et exécuter une application cliente.
* Comparer les architectures 2-tiers et 3-tiers.

Environnement de travail

* Windows 11
* VMware Workstation
* Ubuntu 24
* MariaDB
* Python
* Apache

Contenu du dépôt

Le fichier PDF présenté dans ce dossier correspondent au compte rendu et aux différentes étapes de réalisation du TP. Voici tous les fichiers utilisés pour le dépot:
* Compte rendu.pdf : compte rendu du TP.
* client_lourd.py : application cliente lourde.
* app3tiers/ : fichiers de l’application 3-tiers.
* volume.sql : script SQL relatif au volume.
* volume_annuler.sql : script SQL relatif à l’annulation du volume.
* utilisateurs_tp2.sql : script SQL de gestion des utilisateurs.

Conclusion

Ce TP permet de comprendre les différences entre les architectures 2-tiers et 3-tiers, notamment en matière de répartition des traitements, de communication entre les composants et de maintenance des applications.
